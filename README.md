# Дискретная математика · неклассические логики

Три консольные лабораторные работы. Для ЛР №1 и №2 выбран вариант 4. Команды выполняются из корня репозитория в Python 3.10 или новее. Для запуска программ и тестов достаточно стандартной библиотеки.

| Работа | Что запустить | Материалы |
|---|---|---|
| 1. Верификатор доказательств | `python lab1.py examples/proof.txt` | [Разбор доказательства и правил](reports/lab1.md) |
| 2. Многозначные логики | `python lab2_variant.py` | [Отчёт и вопросы к защите](reports/lab2.md) · [Полные таблицы](reports/lab2-output.txt) |
| 3. Нечёткий вывод Сугено | `python lab3/sugeno.py` | [Отчёт, графики и протоколы трёх экспериментов](reports/lab3/README.md) |

## Ввод своих данных

```console
python lab1.py
python lab2.py "p -> p"
python lab2.py "p -> q" --values p=1/2 q=1/2
python lab2.py "q" --logic L3 --premises "p" "p -> q"
python lab3/sugeno.py --config lab3/config.json --data lab3/incidents.json
python lab3/experiments.py
python -m unittest -v
```

В формулах переменные обозначаются одиночными строчными латинскими буквами. Доступны символы `¬ ∧ ∨ →`, импликация `⊃` и клавиатурная запись `! & | ->`. Приоритет убывает от отрицания к импликации. Цепочка импликаций читается слева направо. При передаче формулы в командной строке используйте двойные кавычки.

В ЛР №3 параметры шести функций принадлежности, пара операций и семь заключений правил задаются в [конфигурации](lab3/config.json). Десять учебных сценариев и обоснования оценок приведены в [исходных данных](lab3/incidents.json). Готовые графики входят в отчёт. Для повторного построения SVG используется `python lab3/plots.py` с установленным пакетом `reportlab`.
